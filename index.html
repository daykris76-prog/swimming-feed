Skills Lab • The 3 Game Winners

  • 1. Starts (Arrow Entry) Tight streamline, lock thumbs, head neutral. Enter through a single hole in the water.
  • 2. Turns (7m Setup) Accelerate into the wall. No breathing inside the flags; drive off in tight streamline.
  • 3. Finishes (Touch First) Head down, zero breaths over the final 5 meters. Hit the touchpad with full fingertip drive.

Strength Lab • Core & Posture

Fuelling & Race Day Bag

  • Pre-Race Fuel: Oats, banana & honey 2–2.5 hrs before warm-up.
  • Deck Hydration: 1L water + electrolyte drink; sip between every race.
  • 30-Min Post Race: Chocolate milk, protein shake, or banana within 20 mins.
  • Deck Rest: Keep warm, stay off feet between prelims & finals on yoga mat.
Publish to GitHub Pages in 3 Minutes

This dashboard is already structured as a single-file static web application (index.html), making it 100% ready for free instant hosting on GitHub Pages.

  1. Create a new repository on GitHub named day-brothers-dashboard (or any name you like). Make it Public.
  2. Upload this file as index.html in the main branch (root directory).
  3. Go to Settings > Pages (in the left sidebar).
  4. Under Build and deployment > Branch, select main and folder / (root), then click Save.
  5. Within 60 seconds, your site will be live at:
    https://<your-username>.github.io/day-brothers-dashboard/
